# הפסקת סיגריה

למי שלא מעשן, אבל לא מוותר על ההפסקה.

מדליקים סיגריה וירטואלית, ובזמן שהיא נשרפת מקבלים נושא לשיחה שמחזיק בדיוק הפסקה אחת.

## איך זה עובד

- **הדלקה:** גוררים את הגפרור אל קצה הסיגריה. אפשר גם להקיש על הסיגריה או ללחוץ על "להדליק".
- **זמן:** כל סיגריה נשרפת בזמן אקראי בין 3 ל-5 דקות, עם גחלת, עשן ואפר שנופל.
- **נושא לשיחה:** 90 נושאים, ונושא לא חוזר עד שעוברים על כולם. לכל נושא שלוש שאלות המשך שעולות בהדרגה במהלך הסיגריה.
- **שיתוף:** העתקת הנושא או שליחה בוואטסאפ.

## הרצה

זה קובץ HTML אחד בלי תלויות ובלי build: פותחים את `index.html` בדפדפן.

אפשר גם להריץ שרת מקומי עם `npm start` ולפתוח את `http://localhost:4173`.

## בדיקות

הבדיקות כתובות ב-[Playwright](https://playwright.dev) ונמצאות ב-`tests/app.spec.js`. הן רצות פעמיים, במסך מחשב ובמסך טלפון, ובודקות:

- שמאגר הנושאים תקין: לכל נושא שלוש שאלות המשך ואין כפילויות.
- הדלקה בכפתור, בהקשה על הסיגריה ובגרירת הגפרור, ושגרירה קצרה מדי לא מדליקה.
- שכל סיגריה נמשכת בין 3 ל-5 דקות, נשרפת, ושאלות ההמשך עולות אחת אחרי השנייה.
- סוף הסיגריה והדלקה של סיגריה חדשה עם נושא אחר.
- שנושאים לא חוזרים עד שעוברים על כולם.
- העתקה ושיתוף בוואטסאפ.
- שהעמוד לא גולל הצידה ושאין שגיאות JavaScript.

הבדיקות לא מחכות 5 דקות אמיתיות: הן מזיזות שעון מדומה קדימה.

הרצה מקומית:

```bash
npm install
npx playwright install chromium
npm test
```

## שחרור גרסה

הקובץ `.github/workflows/ci.yml` מריץ את הבדיקות ב-GitHub Actions:

- **על כל Pull Request:** הבדיקות רצות ומסמנות את ה-PR בירוק או באדום.
- **על כל push ל-`main`:** הבדיקות רצות, והאתר מתפרסם ל-GitHub Pages רק אם כולן עברו. אם משהו נכשל, הגרסה הקודמת נשארת באוויר.

כדי שזה יעבוד, צריך לבחור ב-Settings → Pages → Source את האפשרות **GitHub Actions**.

האפליקציה זמינה בכתובת `https://liori9.github.io/cigarette-break/`.

## הוספת נושאים

הנושאים נמצאים בתחילת הסקריפט ב-`index.html`, בקבוע `RAW`. כל שורה היא נושא אחד ושלוש שאלות המשך, מופרדים ב-`|`:

```
הנושא | שאלת המשך 1 | שאלת המשך 2 | שאלת המשך 3
```
